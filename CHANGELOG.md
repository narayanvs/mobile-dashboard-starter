# Changelog

## 0.1.0-beta.1

Initial public beta.

- Native Home Assistant Community dashboard setup with Demo only, discovery and manual customisation.
- Animated houses, weather and appliances with theme-aware light/dark artwork, fonts and appearance presets.
- Room, lighting, energy, appliance, lab, security, car and calendar templates.
- Flexible user-defined pages, sections, navigation ordering and native/custom HA cards.
- Dashboard-owned mappings and layouts, safe demo controls and clear install/uninstall instructions.
- Screenshot galleries showing demo layouts and the original reference dashboard.
